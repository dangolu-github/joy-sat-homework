Class 16 Guided Homework — Text Structure and Purpose

Joy · Class 16 · 30 direct official questions · 10 function + 10 structure + 10 purpose

How to use this guided homework
  • Try the complete passage and all four choices first.
  • If the passage feels dense, open Check the hint. The hint shortens the reasoning path but does not make the final choice.
  • Questions 1–10: use Content-to-Function Map.
  • Questions 11–20: use Structure Arrow.
  • Questions 21–30: use Purpose = Topic + Job + Scope.
  • For every option, test the marked words for job, order, direction, and scope.

Part I — Sentence or part function: Content-to-Function Map

Questions 1–10: identify the target content, read the context window, and name the target's precise rhetorical job.
