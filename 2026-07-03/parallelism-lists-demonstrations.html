Joy Lesson 07: SAT-Style Parallelism Demonstrations

Annotation Key

Use the colors to bracket equal sentence units. The goal is to see which words are doing the same job.

Demo 1: Three Gerund Phrases

By measuring the shoreline at low tide, photographing the same markers each month, and recording changes in nearby vegetation, the ecology team built a reliable picture of how the marsh was shifting.

  • Parallel unit: three gerund phrases after by.
  • Core skeleton: by measuring, photographing, and recording.

Demo 2: Shared Subject, Shared Tense

The conservator removed the cracked varnish, tested a gentler solvent, and documented each change before returning the painting to the gallery.

  • Parallel unit: three past-tense verbs with one subject.
  • Core skeleton: conservator removed, tested, and documented.

Demo 3: Infinitives After One Purpose

The accessibility team redesigned the ticket kiosk to enlarge the text, to add audio instructions, and to simplify the payment screen.

  • Parallel unit: three to + verb phrases.
  • Core skeleton: redesigned to enlarge, to add, and to simplify.

Demo 4: Not Only / But Also

The oral-history project is useful not only for preserving family stories but also for helping younger residents understand local migration patterns.

  • Parallel unit: for + gerund phrase on both sides.
  • Core skeleton: not only for preserving but also for helping.

Demo 5: Rather Than

When the first model failed, the students chose to adjust the angle of the blades rather than replace the entire fan assembly.

  • Parallel unit: to adjust rather than replace; the to is shared.
  • Core skeleton: chose to adjust rather than replace.

Demo 6: Comparison of Features

The new water filter's flow rate is slower than that of the older model, but its smaller pores remove more sediment.

  • Comparable items: flow rate vs. flow rate.
  • Core skeleton: flow rate is slower than that of the older model.

Demo 7: From / To

The media exhibit follows public communication from handwritten notices posted in town squares to encrypted messages sent through mobile apps.

  • Parallel unit: from noun phrase to noun phrase.
  • Core skeleton: from notices to messages.

Demo 8: As / As

Although the portable microscope is as precise as the classroom model, it is lighter and can be packed into a field bag.

  • Comparison structure: as + base adjective + as.
  • Core skeleton: as precise as the model.
